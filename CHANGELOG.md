# Changelog

All notable changes to the **Ready2Merge** extension will be documented in this file.

## [0.1.0] - 2024-02-07

### Added
- Initial release of Ready2Merge.
- **Repository DNA**: Learn repository patterns (Console logs, TODOs, Naming conventions).
- **PR Readiness Check**: Analyze current Git changes against the project baseline.
- **Repository Insights**: High-level overview of codebase health and patterns.
- **Pinpoint Navigation**: Clickable links in output to jump directly to code lines/columns.
- **Environment Check**: Detect missing `.env.example` files.
- **Docker Support**: Track Dockerfile instruction casing consistency.
- **Naming Conventions**: Detect drift in `camelCase` vs `snake_case` patterns.
